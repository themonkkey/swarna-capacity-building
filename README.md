# Capacity Building · Swarna Andhra @2047

Standalone site for the capacity-building programme of the Andhra Pradesh
Planning Department: the programme record across all 28 districts, by
district and constituency. Carved out of the main Swarna Andhra @2047 site
(themonkkey/Version-2); this repo serves only the capacity page.

Static site — no build step. Deploy root: repository root.
